##COMMITS
svp l'équipe, pour qu'on se comprenne tous j'aimerais qu'à chaque commit vous faites ces étapes :
-Pour chaque ajout, vous faites une branche et qui porte le nom de l'ajout, exemple :
  je créé une branche feat/AjoutDesIllustrations pour commit les nouvelles illustrations de personnages, pas besoin de décrire entièrement l'ajout dans le nom de la branche
  (ce sera au début soit feat pour un ajout soit fix pour une correction)
-Quand vous faites un commit vous mettrez dans le titre du commit : "feat(Ajout): état d'avancement" (ou fix donc)
-Vos PR auront juste le même titre que le commit (ou alors vous en faites un différent si besoin il n'y a aucun problème)
-Mais essayez de faire une description qui nous permet de comprendre l'ajout en détail si c'est trop flou mais c'est facultatif on aura qu'à regarder les fichiers modifiés.
-Lorsque vous mergez votre PR, SUPPRIMEZ VOTRE BRANCHE car tout faire sur la même branche ça va nous faire des problèmes de divergence et c'est compliqué, personne ne veut faire ça...

Vous n'êtes pas obligés de tout suivre mais faites au moins en sorte de faire une branche par ajout et la supprimer quand elle est inutile comme ça on aura presque plus de 
problèmes de divergence, merci !!
